The network

Ten layers of 100 units, hl = φ(hl−1 Wl), with biases 0, on a minibatch of 256 random inputs. The backward pass starts from a gradient with standard deviation 1 at the top and multiplies it, layer by layer, by φ′ and by Wl⊤, as in backpropagation. Saturated units are units whose input z lies where φ′(z) < 0.01.

The model

      
Linear regression ŷ = w1 x1 + w2 x2 on n = 256 examples with centered features, mean squared error.
      Along each weight the loss is a parabola with curvature sj2, the variance of the feature, so one full-batch step multiplies the error of wj by 1 − 2ηsj2.
      Each epoch shuffles the examples and makes 256/b updates.
